# ✨ Key Features

## 🤖 AI-Powered Portfolio Assistant

The portfolio includes an intelligent chatbot capable of answering questions about:

* My experience
* Technical skills
* Education
* Projects
* Certifications
* Current work
* Contact information

### Features

* Primary AI powered through an N8N Automation Agent
* Automatic fallback to OpenAI ChatGPT
* Never goes offline if one service becomes unavailable
* Uses a live CV knowledge base
* Context-aware responses

---

## 🎤 Voice Conversation

Visitors can communicate naturally using voice.

Features include:

* Speech-to-text input
* Text-to-speech responses
* Hands-free interaction
* Browser Web Speech API integration

---

## 📧 Lead Capture System

Every chatbot conversation can become a potential business lead.

Visitors provide:

* Name
* Email
* Optional WhatsApp number

When the conversation ends:

* Chat transcript is generated
* Visitor details are collected
* Transcript is automatically emailed via EmailJS

---

## 📊 Live Project Metrics

Instead of displaying static project information, the portfolio fetches real-time statistics from deployed applications.

Metrics include:

* Active users
* Database counts
* System uptime
* Performance metrics
* Security rating
* Auto-refresh every minute
* Smart caching to reduce API calls
